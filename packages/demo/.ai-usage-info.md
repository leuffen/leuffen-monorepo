# @leuffen/demo – AI usage information

This package is the reference implementation for new packages in the monorepo.

## Public API

Runtime, stylesheet, and test entrypoints live directly in the package root so they can be imported without a build during development.

```ts
import { greet } from '@leuffen/demo';
import '@leuffen/demo/index.css';

const message = greet('Leuffen');
```

## Conventions

- Keep public entrypoints such as `index.ts` and `index.css` in the package root.
- Place unit tests next to their entrypoint as `*.spec.ts`.
- Keep the package ESM-only.
- Add package-specific Nx targets only when they cannot be inferred from existing configuration.
- Build output belongs in the package-local `dist/`; never commit it.
- Update this file whenever the public API or required usage pattern changes.
