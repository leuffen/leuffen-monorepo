# @leuffen/demo – AI usage information

This package is the reference implementation for new packages in the monorepo.

## Public API

Export every supported public symbol from `src/index.ts`. Consumers must import from `@leuffen/demo`, not from internal source paths.

```ts
import { greet } from '@leuffen/demo';

const message = greet('Leuffen');
```

## Conventions

- Keep runtime code in `src/`.
- Place unit tests next to their source as `*.spec.ts`.
- Keep the package ESM-only.
- Add package-specific Nx targets only when they cannot be inferred from existing configuration.
- Build output belongs in `dist/packages/demo`; never commit it.
- Update this file whenever the public API or required usage pattern changes.
