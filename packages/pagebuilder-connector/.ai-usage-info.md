# @leuffen/pagebuilder-connector

Import the package once to register two Web Components. Place the invisible
connector before edit buttons so its `connectedCallback` initializes the
shared configuration.

```html
<leuffen-pagebuilder-connector
  base-url="https://pagebuilder.example.com/edit"
  subscription-id="site-123"
  scope-id=""
  file-name="pages/home.md"
></leuffen-pagebuilder-connector>

<leuffen-pagebuilder-edit-button></leuffen-pagebuilder-edit-button>

<script type="module">
  import '@leuffen/pagebuilder-connector';
</script>
```

`base-url`, `subscription-id` and `file-name` are required; `scope-id`
may be empty or omitted. On click the edit button reads the shared config,
forms the PageBuilder URL with `subscription`, `path` and optional `scope`,
and navigates via `window.location.assign()`. It renders a `<button>`
containing an inline SVG, never an anchor or `href`.

With incomplete configuration clicking has no effect. The PageBuilder is
responsible for authorization.
