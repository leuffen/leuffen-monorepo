# @leuffen/pagebuilder-connector

Register the two Web Components by importing the package once.
The connector stores the PageBuilder target; buttons use its configuration.

```html
<leuffen-pagebuilder-connector
  base-url="https://pagebuilder.example.com/edit"
  subscription-id="site-123"
  scope-id=""
  file-name="pages/home.md"
></leuffen-pagebuilder-connector>
<leuffen-pagebuilder-edit-button></leuffen-pagebuilder-edit-button>

<script type="module">
  import '@leuffen/pagebuilder-connector';
</script>
```

The invisible connector requires `base-url`, `subscription-id` and
`file-name`; `scope-id` is optional. It generates the query parameters
`subscription`, `path` (from `file-name`) and, when provided, `scope`.
The button displays an inline SVG edit icon. It uses the closest ancestor
connector or, if there is none, the first connector in the document.

When configuration is incomplete the button has no navigation target.
The PageBuilder is responsible for authorization.
