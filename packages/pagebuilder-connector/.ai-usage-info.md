# @leuffen/pagebuilder-connector

Import the package once to register `<leuffen-pagebuilder-edit>`. It renders an
inline SVG edit icon linking to the PageBuilder for the current page.

```html
<script>
  window['micx-subscription'] = { subscriptionId: 'site-123' };
</script>
<leuffen-pagebuilder-edit
  base-path="https://pagebuilder.example.com/edit"
></leuffen-pagebuilder-edit>
<script type="module">
  import '@leuffen/pagebuilder-connector';
</script>
```

The link adds `subscription=site-123` and `path=<current pathname>` as URL
query parameters. Clicks refresh the link from the latest subscription data.

You can override the ID with `subscription-id="site-456"`. The component
reads the ID from `window['micx-subscription']` by default, also accepting
`window['mix-subscription']` or `window.micxSubscription`. The global may
contain an ID string or an object with `subscriptionId` or `id`. An object
may also provide `pagebuilderBasePath` or `basePath` instead of the
`base-path` attribute.

If either the subscription ID or base path is missing, the edit icon has no
navigation target. The host page remains responsible for access control.
