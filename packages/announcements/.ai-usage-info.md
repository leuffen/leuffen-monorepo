# @leuffen/announcements – AI usage information

Use this package to retain the existing `@leuffen/liweco-base` vacation
announcement behavior with the renamed Leuffen components. Do not introduce a
second data format: the components read `window.openhours` directly.

## Component usage

Set `window.openhours` before the components initialize.

```html
<script>
  window.openhours = {
    _editor: 'openhours',
    table: [],
    _status_values: [],
    json: [],
    vacation: [
      {
        from: '2026-08-03',
        till: '2026-08-14',
        title: '**Praxisurlaub**',
        short_text: 'Unsere Praxis bleibt geschlossen.',
        text: 'Ab dem 17. August sind wir wieder für Sie da.',
      },
    ],
  };
</script>

<leuffen-announcements>Keine aktuellen Hinweise</leuffen-announcements>
<leuffen-vacation-modal></leuffen-vacation-modal>

<script type="module">
  import '@leuffen/announcements';
</script>
```

Do not set `data` or `source` properties. They are not part of this package. Both
components wait for DOM readiness and then retain the original 100 ms startup
delay before reading `window.openhours`.

## Announcement list

Use `data-class` to pass a class to the generated container.

```html
<leuffen-announcements data-class="practice-announcements">
  Keine aktuellen Hinweise
</leuffen-announcements>
```

The generated hooks are stable:

```css
leuffen-announcements.no-announcements {
  display: none;
}

[data-owner='leuffen-announcements'] {
  display: grid;
  gap: 1rem;
}

[data-owner='leuffen-announcement'] {
  margin: 0;
}
```

The list uses `vacation[].title`. The modal uses `vacation[].title` and
`vacation[].text`. `short_text` stays in the existing data format but is not read
by these two components, matching the old implementation.

## Business logic

Use the exported `OfficeHours` class when the same result is needed outside the
components.

```ts
import { OfficeHours } from '@leuffen/announcements';

const officeHours = new OfficeHours();
officeHours.loadStruct(window.openhours);

if (officeHours.isVacation(null)) {
  const activeVacation = officeHours.getVacation(null);
}

const allCurrentAndFutureVacations = officeHours.getUpcomingVacation(null);
const nextThirtyDays = officeHours.getUpcomingVacation({ days: 30 });
```

Preserve the original `Date` behavior when extending this package:

- strings are converted with `new Date(value)`;
- a vacation's `till` date is changed to local 23:59:59.999;
- `null` means the current date;
- `getUpcomingVacation(null)` keeps vacations whose end is not in the past;
- limited intervals use the original three overlap comparisons.

## Modal

The controller must continue to call the programmatic dialog:

```ts
const vacation = officeHours.getVacation(null);
if (vacation !== null) {
  await LeuffenVacationDialog.show(vacation);
}
```

Do not add inline modal markup to `<leuffen-vacation-modal>`. The controller stays
hidden, while `LeuffenVacationDialog` handles presentation and dismissal.
