# @leuffen/announcements – AI usage information

Use this package for time-bound news and vacation replacement information on
practice websites. Importing the package registers `<leuffen-announcements>` and
`<leuffen-vacation-modal>`.

## Declarative usage

Prefer a JSON script as the shared data source when both components are used on a
page. `startsOn` and `endsOn` are inclusive ISO calendar dates, not timestamps.

```html
<script type="application/json" id="practice-announcements">
  {
    "version": 1,
    "locale": "de-DE",
    "timeZone": "Europe/Berlin",
    "announcements": [
      {
        "id": "summer-vacation-2026",
        "type": "vacation",
        "startsOn": "2026-08-03",
        "endsOn": "2026-08-14",
        "title": "Praxisurlaub",
        "summary": "Unsere Praxis bleibt geschlossen.",
        "content": "Ab dem 17. August sind wir wieder für Sie da.",
        "replacements": [
          {
            "name": "Praxis Dr. Beispiel",
            "phone": "+49 221 123456",
            "url": "https://example.org",
            "note": "Bitte vorher telefonisch anmelden."
          }
        ]
      }
    ]
  }
</script>

<leuffen-announcements source="#practice-announcements">
  Keine aktuellen Hinweise
</leuffen-announcements>
<leuffen-vacation-modal source="#practice-announcements"></leuffen-vacation-modal>

<script type="module">
  import '@leuffen/announcements';
</script>
```

The announcements component lists active and future entries. The modal component
opens the first active vacation with the programmatic Nextrap dialog component.
It keeps itself hidden and should not contain presentation markup.

## Direct data assignment

Use the `data` property when the application already owns the data. Do not encode
the object into an HTML attribute.

```ts
import '@leuffen/announcements';
import type { AnnouncementData, LeuffenAnnouncements } from '@leuffen/announcements';

const data: AnnouncementData = {
  version: 1,
  locale: 'de-DE',
  timeZone: 'Europe/Berlin',
  announcements: [
    {
      id: 'new-phone-hours',
      type: 'announcement',
      startsOn: '2026-09-01',
      endsOn: '2026-09-30',
      title: 'Neue Telefonzeiten',
      summary: 'Montag bis Freitag von 8 bis 12 Uhr.',
    },
  ],
};

const element = document.querySelector<LeuffenAnnouncements>('leuffen-announcements');
if (element) element.data = data;
```

For deterministic previews and tests, set the component's `today` property and
call `refresh()` after changing it.

```ts
const element = document.querySelector<LeuffenAnnouncements>('leuffen-announcements');
if (element) {
  element.today = '2026-09-10';
  element.refresh();
}
```

## Display options

Keep an entry out of the list with `list: false`. Prevent a vacation from opening
as a dialog with `dialog: 'never'`.

```ts
const vacation = {
  id: 'internal-vacation',
  type: 'vacation' as const,
  startsOn: '2026-12-24',
  endsOn: '2026-12-31',
  title: 'Praxisurlaub',
  display: {
    list: false,
    dialog: 'never' as const,
  },
};
```

## Business logic without DOM

Use `AnnouncementSchedule` instead of duplicating date comparisons. The API uses
`Temporal.PlainDate` semantics and the configured time zone for today's date.

```ts
import { AnnouncementSchedule } from '@leuffen/announcements';

const schedule = new AnnouncementSchedule(data);

const active = schedule.getActive('2026-08-10');
const activeVacation = schedule.getActiveVacation('2026-08-10');
const nextThirtyDays = schedule.getUpcoming({
  from: '2026-08-01',
  days: 30,
});
```

## Legacy migration

`window.openhours` remains an automatic fallback when neither `data` nor `source`
is provided. For new code, convert legacy data explicitly and then use the normal
API.

```ts
import { fromLegacyOpenHours } from '@leuffen/announcements';

const data = fromLegacyOpenHours({
  vacation: [
    {
      from: '2026-08-03',
      till: '2026-08-14',
      title: 'Praxisurlaub',
      short_text: 'Unsere Praxis bleibt geschlossen.',
      text: 'Ab dem 17. August sind wir wieder für Sie da.',
    },
  ],
});
```

## Errors and styling hooks

Listen for `leuffen-announcements-error` when invalid JSON or invalid dates should
be reported by the host application. Style generated markup through the data
owners and the host state; do not depend on undocumented element nesting.

```css
leuffen-announcements.no-announcements {
  display: none;
}

[data-owner='leuffen-announcements'] {
  display: grid;
  gap: 1rem;
}
```
