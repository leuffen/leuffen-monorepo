# @leuffen/announcements

Nutze `window.openhours` direkt, keine `data`- oder `source`-Properties.
Das Datenformat ist in [openhours.schema.json](openhours.schema.json)
beschrieben. Setze das Objekt vor der Initialisierung der Komponenten.

```html
<script>
  window.openhours = {
    _editor: 'openhours/v1',
    _status_values: ['Offen', 'Nach Vereinbarung'],
    table: [{ day: 'Montag', time: '08:00 – 12:00' }],
    json: [{ dayOfWeek: '1', from: '08:00', till: '12:00', status: 'Offen' }],
    vacation: [
      {
        type: 'vacation',
        from: '2026-12-24',
        till: '2026-12-31',
        title: '**Urlaub vom 24.12. bis 31.12.**',
        text: 'Bitte wenden Sie sich an unsere Vertretung.',
        popup: true,
        is_closed: true,
        variant: 'info',
      },
      {
        type: 'info',
        from: '',
        till: '',
        title: 'Geänderte Sprechzeiten',
        text: 'Bitte vereinbaren Sie einen Termin.',
        variant: 'warning',
      },
      {
        type: 'popup',
        from: '2026-12-01',
        till: '2026-12-07',
        title: 'Telefonische Erreichbarkeit',
        text: 'Bitte nutzen Sie unser Kontaktformular.',
        variant: 'danger',
      },
    ],
  };
</script>

<!-- Alle Meldungen an einer Stelle -->
<leuffen-announcements>Keine aktuellen Hinweise</leuffen-announcements>

<!-- Urlaubsankündigungen im Header -->
<leuffen-announcements type="vacation" data-class="style-ribbon">
</leuffen-announcements>

<!-- Hinweise im Seiteninhalt -->
<leuffen-announcements type="info" data-class="practice-notices">
</leuffen-announcements>

<!-- Optional: Popup-Meldungen zusätzlich im Seiteninhalt -->
<leuffen-announcements type="popup"></leuffen-announcements>

<!-- Automatisches Popup einmal pro Seite -->
<leuffen-vacation-modal></leuffen-vacation-modal>

<script type="module">
  import '@leuffen/announcements';
</script>
```

Ohne Typ werden alle relevanten Meldungen angezeigt; `type` filtert nach
`vacation`, `info` oder `popup`. Urlaub zeigt nur den Titel, auch vor dem
Beginn. Hinweise und Popup-Meldungen zeigen Titel und Text im aktiven
Zeitraum. Leere Datumsgrenzen bedeuten keine Begrenzung. Der Modal-Controller
öffnet den ersten aktiven Typ `popup` oder Urlaub mit `popup: true`.

Jede Meldung ist ein eigenes DIV mit `announcement`,
`announcement-<type>` und `announcement-variant-<variant>`, optional
`has-popup` und `is-closed`. `data-class` stylt den Container.
Fallback-Inhalte bleiben erhalten; bei leerer Liste erhält das Host-Element
`no-announcements`.

Altdaten ohne Typ bleiben Urlaub mit Popup und Schließung, sofern diese
Flags nicht angegeben sind. Expliziter Urlaub wird nur mit `is_closed:
true` als geschlossen gewertet.

```ts
import { OfficeHours } from '@leuffen/announcements';

const officeHours = new OfficeHours();
if (window.openhours) {
  officeHours.loadStruct(window.openhours);
  const infos = officeHours.getAnnouncements('info');
  const activePopup = officeHours.getActivePopup();
  const upcomingVacations = officeHours.getUpcomingVacation(null);
}
```
