# AI usage information: @leuffen/announcements

Use `<leuffen-announcements>` to render active and upcoming announcements and
`<leuffen-vacation-modal>` to open the active vacation through the programmatic Nextrap
dialog component. Prefer the `AnnouncementData` v1 format through the `data` property
or a JSON script selected with `source`. `window.openhours` is a compatibility fallback
only. Dates are inclusive ISO calendar dates; do not convert them to timestamps.
